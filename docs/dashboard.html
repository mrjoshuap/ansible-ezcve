CVE report dashboard

These files stay in this browser tab. Nothing is sent to GitHub Pages or any other server. Closing the tab, or choosing Clear, drops them. A report can include process names from the host.

Create the JSON files

Run a role with its report directory set. For CVE-2026-98432:

- name: Audit hosts for CVE-2026-98432
  hosts: all
  gather_facts: true
  become: true
  roles:
    - role: mrjoshuap.ezcve.cve_2026_98432_check
      vars:
        cve_2026_98432_check_report_dir: ./cve-reports

The role writes one <inventory_hostname>.json file per host on the controller. Each file is that host's summary object. Another role uses <role>_report_dir the same way and should use its own directory, so a later run does not overwrite the same hostname. Choose the JSON files or that folder below. CSV files are ignored. An array of summary objects in one file is accepted too.
